# VB.NET Hospital ERP Starter

A responsive open-source Hospital ERP starter built using ASP.NET Web Forms, VB.NET and Bootstrap.

Designed for hospitals, clinics and healthcare software teams looking for a ready-to-use healthcare ERP foundation.

---

## Features

### Patient Registration
- UHID auto generation
- full name
- age
- gender
- mobile number
- address
- emergency contact

### Responsive UI
- Bootstrap-based layout
- desktop/tablet/mobile friendly
- clean healthcare card design

### ERP Ready Structure
- registration module
- billing-ready structure
- appointment-ready pages
- future lab integration

### ASP.NET Web Forms
- VB.NET backend
- reusable master page
- modular forms

---
